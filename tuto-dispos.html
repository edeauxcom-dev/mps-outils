Cases dorées = dernier lundi/mardi/mercredi du mois = présentiel à Marseille toute la journée (7h). Cochez uniquement si vous pouvez vous déplacer !
ℹ️
Cases grisées "Déjà couvert" = un autre formateur est déjà positionné sur ce créneau. Vous pouvez quand même cocher si vous êtes aussi disponible — Stéphanie arbitrera.
4
Cocher ses disponibilités et valider

Cochez toutes les cases où vous êtes disponibles. N'oubliez pas les présentiels du dernier jour du mois si vous pouvez venir à Marseille.

Une fois terminé, cliquez sur "Valider mes disponibilités" en bas de page.

⚠️ Une fois validé, vous ne pouvez plus modifier directement. Si vous avez besoin de changer quelque chose, utilisez le bouton "Envoyer une demande de modification" qui apparaît après validation — ça enverra un message automatique à Stéphanie.
5
C'est tout ! 🎉

Vos disponibilités sont enregistrées. Stéphanie reçoit une alerte automatique si des créneaux restent non couverts une fois que tout le monde a répondu.

Vous recevrez le planning finalisé sur Slack une fois l'arbitrage fait.

🙏 Merci de jouer le jeu sur les présentiels — c'est ce qui nous permet d'anticiper les déplacements à Marseille sereinement !
